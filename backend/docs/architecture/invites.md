# Приглашения

Код: `src/invites/`, схема — `src/database/schema/invites.schema.ts`. Клиент —
[groups-and-members.md](../../../frontend/docs/architecture/groups-and-members.md).

```
POST /api/groups/:id/invites { claimMemberId? }  → { code, url: APP_ORIGIN/join/<code>, expiresAt, claimMemberId }
GET  /api/invites/:code                          → превью (публично)
POST /api/invites/:code/accept                   → { groupId, memberId, alreadyMember }
```

- Код — 16 случайных байт (base64url), срок — 7 дней.
- Превью открывается без входа: название группы, кто пригласил, сколько участников, кого «заберёшь». Вступить
  можно только с подтверждённым кошельком (access-токен).
- **Общая** ссылка работает для любого числа людей до истечения срока (в пределах лимита 50 участников). Имя по
  умолчанию — короткий адрес; если оно занято, добавляется «2», «3» (`freeName`).
- **Персональная** (на участника без кошелька) срабатывает один раз: вошедший становится этим участником вместе
  с его расходами и долгами. Создать её можно только на участника этой группы без кошелька, иначе 409.
- Вход выполняется в одной транзакции с блокировками приглашения, группы и пользователя. Одну персональную
  ссылку не заберут двое (второй получит 410), лимиты не обойти параллельными запросами. Если ты уже в группе,
  ответ — `alreadyMember: true`.
- Общую ссылку стоит отправлять в доверенный чат.

## Список и отзыв

```
GET    /api/groups/:id/invites         → действующие ссылки: code, url, срок, кто пригласил, на кого, uses
DELETE /api/groups/:id/invites/:code   → 204
```

- Действующая — не истекла, не отозвана, персональная — ещё не использована. До 50 штук.
- Отозвать может любой участник группы: отзыв только закрывает доступ. После этого превью и вход
  отвечают 410 «Приглашение отозвано». Повторный отзыв или чужая группа — 404.
- При удалении участника без кошелька все персональные ссылки на него отзываются автоматически.
