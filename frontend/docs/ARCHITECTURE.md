# Архитектура Divra (frontend)

Документ — точка входа. Детали по каждой подсистеме лежат в `docs/architecture/`.
Любое архитектурное решение фиксируется здесь (таблица ниже) и в соответствующем файле.

## Стек

| Задача            | Решение                                                           |
| ----------------- | ----------------------------------------------------------------- |
| UI                | React 19 + React Compiler, Vite 8, TypeScript 7                   |
| Архитектура       | Feature-Sliced Design, проверяется `steiger`                      |
| Роутинг           | React Router (data router) + `SessionGate`                        |
| Состояние клиента | zustand (только сессия кошелька)                                  |
| Данные с сервера  | TanStack Query                                                    |
| Валидация         | zod — на всех границах (env, API, localStorage)                   |
| Кошельки          | Слой адаптеров `shared/lib/wallets`, Solana через Wallet Standard |
| Дизайн-система    | `shared/ui` + токены в `app/styles/variables.css`                 |

## Слои

```
src/
├── app/                  точка входа, провайдеры, роутер, глобальные стили
│   ├── router/           routes, router.tsx, AppLayout, SessionGate (доступ по статусу сессии), ленивые страницы
│   └── state/            QueryProvider, WalletSessionSync, FeatureFlagsSync, auth-bridge (токен для API-клиента)
├── pages/
│   ├── connect/          шаг 1 — выбор и подключение кошелька
│   ├── verify/           шаг 2 — подпись транзакции-вызова от бэкенда
│   ├── home/             главная: итог по всем группам, список групп, «Недавнее»
│   ├── group/            группа: баланс, «Кто кому», расходы, переключатель валюты
│   ├── add-expense/      форма расхода (отдельный чанк)
│   ├── members/          участники: приглашение по ссылке, добавление по имени
│   ├── join/             /join/:code — принять приглашение (доступно без входа)
│   ├── request/          «Запросить» и «Отправленные»
│   ├── pay-request/      /r/:code — страница оплаты для друга (без входа)
│   ├── settle/           «Рассчитаться» одной транзакцией
│   ├── settings/         валюта, стейблкоин, фича-флаги, аккаунт
│   └── error/, not-found/
├── features/
│   └── wallet-auth/      подключение, подтверждение, отключение кошелька
├── entities/
│   ├── currency/         настройки валюты и стейблкоина, useMoney
│   ├── expense/          категории расходов (иконки, подписи)
│   └── wallet/           сессия кошелька (zustand) + синхронизация с расширением
└── shared/
    ├── api/              HTTP-клиент, API по доменам (zod-схемы = контракт с бэкендом), mock бэкенда
    ├── config/           env (zod), ROUTES, сети, валюты, стейблкоины, фича-флаги
    ├── lib/wallets/      адаптеры кошельков: core/ + solana/ (+ ethereum/ ton/ tron/ позже)
    ├── lib/…             feature-flags, format, encoding, animation, classnames, test
    └── ui/               компоненты дизайн-системы
```

Импорты идут только сверху вниз: `app → pages → features → entities → shared`.

## Поток входа

```
/connect ──(кошелёк подключён)──▶ /verify ──(подпись принята бэкендом)──▶ /
    ▲                                 ▲                                     │
    └──── отзыв доступа в расширении ─┴──── смена аккаунта в расширении ────┘
```

Переходы не вызываются вручную: страницы обёрнуты в `SessionGate`, который смотрит на
`status` в сторе и перенаправляет сам. Подробно — [wallet-verification.md](architecture/wallet-verification.md).
