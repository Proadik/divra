# Валюты и курсы

## Что где

| Что                                   | Где                                                                                        | Почему                                                  |
| ------------------------------------- | ------------------------------------------------------------------------------------------ | ------------------------------------------------------- |
| Валюта ввода по умолчанию, стейблкоин | `entities/currency` — zustand + persist (`divra.preferences`), zod на чтении               | Предпочтение интерфейса на устройстве, бэкенду не нужно |
| Списки валют, символы                 | `shared/config/currencies.ts`                                                              | Нужны и стору, и схемам API                             |
| Курсы                                 | `shared/api/rates` — `GET /rates?base=USD`, кэш TanStack Query 10 минут (`RATES_STALE_MS`) | Курс общий для всех экранов, запрос один                |

## Как записывается расход

1. Пользователь вводит сумму и точные доли в валюте ввода (по умолчанию из настроек, в форме меняется для одного расхода).
2. Доли считаются в центах этой валюты — та же логика `computeSplit`.
3. Итог переводится в доллары: `round(центы / курс)`. Стейблкоин = доллар 1:1, поэтому это и есть сумма в USDC/USDT.
4. Доли переводятся тем же `distribute` пропорционально фиатным долям — сумма долей совпадает с итогом до цента.
5. В запрос уходят суммы в долларах и `original: { currency, amount, rate }`. Для USD `original` не отправляется.

В списке расходов исходная сумма показывается рядом с долларовой: «Тимур · сегодня · 20 616 ₸».

## Отображение в группе

Над карточкой баланса — переключатель «USDC | KZT ₸» (стейблкоин из настроек и валюта ввода).
Выбор хранится в настройках (`amountsIn`) и действует во всех группах.

- Суммы в данных остаются в долларах; в фиат пересчитываются только при показе (`pages/group/lib/money.ts`).
- Баланс и долги — по текущему курсу. Расход, введённый в той же валюте, показывается
  исходной суммой и по курсу дня записи, остальные — по текущему курсу.
- Под переключателем видно, по какому курсу пересчитано и что расчёт всё равно идёт в стейблкоине.
- Нет курса — показываем в стейблкоине и пишем, что курс недоступен.

## Почему храним курс

Курс меняется, а долги в группе — нет. Расход фиксируется в долларах на момент записи,
`rate` нужен, чтобы показать, по какому курсу пересчитали, и для будущего редактирования.

## Как добавить валюту

1. `shared/config/currencies.ts`: код в `FIAT_CURRENCIES`, символ в `FIAT_SYMBOLS`, название в `FIAT_NAMES`.
   Последние два — `Record` по всем валютам: TypeScript не соберёт проект, пока их не заполнишь.
2. Мок: курс в `shared/api/mock/rates.ts` — там тоже `Record<FiatCurrency, number>`.
3. Бэкенд: отдавать курс в `GET /rates`.

Всё остальное — схемы, настройки, форма, пересчёт — берёт список из конфига.

Порядок выкатки не важен: `ratesSchema` терпимая. Неизвестные валюты в ответе отбрасываются,
недостающие просто отсутствуют. Если бэкенд ещё не отдаёт курс новой валюты, выключится только
она — форма напишет «Курс недоступен», группа покажет суммы в стейблкоине, — остальные работают.

В настройках валюты — список с нативными radio, а не сегменты: число валют не ограничено.

## Ограничения

- Мок отдаёт фиксированные примерные курсы. Настоящий бэкенд берёт их у провайдера и кэширует.
- Отклонение USDC/USDT от доллара не учитывается: для бытовых сумм оно в пределах копеек.
