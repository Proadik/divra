# UI

Компоненты — `src/shared/ui` (дизайн-система Divra, направление A «Calm Fintech»).
Значения — только токены из `src/app/styles/variables.css`.

## Главная (`pages/home`)

```
GroupHeader      ← знак Divra · название и участники · меню (кошелёк, отключить)
BalanceCard      ← мой баланс, аватары, «Рассчитаться» / «Запросить»
DebtsSection     ← «Кто кому»: упрощённые переводы с моим участием
ExpensesSection  ← «Расходы» + индикатор Live
.home__fab       ← «Добавить расход»
```

Данные — один запрос `getGroupOverview` (TanStack Query). Хелперы (`findMember`, `toneOf`,
`toPerson`, `CATEGORY_ICONS`) — в `pages/home/lib/group.ts`.

«Добавить расход» ведёт на `/expenses/new`. Пока без действия (помечены TODO): «Рассчитаться», «Запросить».

Меню в шапке — нативный `popover` (без JS-состояния): подключённый кошелёк и «Отключить кошелёк».

## Закреплённая кнопка «Добавить расход»

```css
.home__fab {
  position: sticky;
  bottom: var(--space-6);
  margin-top: auto;
}
```

- Кнопка стоит последней в потоке страницы. Пока контент выше экрана — `sticky` держит её
  на 24px от низа поверх списка.
- Когда пользователь доскроллил до конца, она оказывается на своём месте в потоке,
  а под ней остаётся нижний отступ страницы (`padding-bottom: var(--space-6)`).
- `margin-top: auto` прижимает кнопку к низу, если контента мало.
- Обёртка пропускает клики (`pointer-events: none`), сама кнопка — нет: строки под
  прозрачной частью обёртки остаются кликабельными.

Никаких слушателей скролла и `IntersectionObserver` — только CSS.
Тот же приём у кнопки «Сохранить расход» в форме (`.add-expense__footer`).

## Аватары

`toneFor(id)` (хеш) годится, когда человек один. В списках одной группы цвет
назначается по порядку участника — `toneOf(group, id)` — чтобы цвета не совпадали.

## Тексты

Подписи не зависят от рода и падежа: «вернёт тебе», «ты вернёшь», «Тимур · сегодня»,
«доля 21.00», «вернут 180.00», «без тебя». Числительные — `pluralize`
(`shared/lib/format/plural.ts`, Intl.PluralRules): «3 перевода», «4 участника».

Сумма в карточке баланса — 36px (было 48): крупно, но не перетягивает внимание с действий.

## Состояния элементов (hover / active / focus)

Правила для любого интерактивного элемента:

| Состояние     | Как выглядит                                                                                                                                 | Где задано                                                                         |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| hover         | Фон на ступень темнее (`--surface-hover`, `--accent-hover`, `--inverse-hover`, `--sunken-hover`)                                             | Только внутри `@media (hover: hover)` — на тач-экранах hover «залипает» после тапа |
| active        | Ещё на ступень темнее (`--surface-active`, `--accent-active`, `--inverse-active`) + `scale(var(--press-scale))` = 0.97; иконкам-кнопкам 0.92 | Без медиазапроса — работает и на телефоне                                          |
| focus-visible | Кольцо 2px `--focus` с отступом 2px; у полей ещё и подпись строки становится `--accent`                                                      | Только с клавиатуры, мышь кольцо не включает                                       |
| disabled      | `opacity: 0.45`, `cursor: not-allowed`, без hover и active (`:not(:disabled)`)                                                               | —                                                                                  |

- Переходы — `--duration-fast` (120ms) и `--ease-out`. При системной настройке «Уменьшить движение»
  длительность сводится к нулю (`app/styles/index.css`).
- Строка-кнопка списка подсвечивается с выходом за края на 12px через `box-shadow`,
  поэтому разделители между строками не сдвигаются.
- Чекбокс подсвечивается кольцом `--accent-soft`, в том числе при наведении на всю строку-`label`.
- Новые токены — в `app/styles/variables.css` для обеих тем и в `design-system/tokens/tokens.json`.
